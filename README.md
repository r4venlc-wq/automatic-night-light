# Automatic Night Light

A simple Arduino project using an LDR (light-dependent resistor) to automatically control an LED based on the surrounding light level.

## Components

- Arduino Uno
- LDR
- LED
- Resistor
- Breadboard

## How it works

The LDR measures the surrounding light level.

- Low light → LED turns on
- Bright light → LED turns off

## What I learned

- Reading analog sensor values
- Using `analogRead()`
- Using `if/else` conditions
- Controlling an LED with Arduino
- Working with an LDR sensor
